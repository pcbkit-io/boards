# Weather station

An Arduino Nano reads an SHT31 and shows the temperature and humidity large on an OLED, with the dew point and how the air feels, the day's lowest and highest and a graph of the last two minutes. Change the weather in the lab; the button turns the pages.

This project began as the demo “Weather station” of PCBKit (https://pcbkit.io): https://app.pcbkit.io/demo/nano-weather-station. Placed and routed by PCBKit; the sketch builds and runs in the browser.
