# Pong

Pong on the pocket console: you on the left with up and down, the computer on the right; the ball speeds up with every return and leaves the paddle at an angle. First to seven.

This project began as the demo “Pong” of PCBKit (https://pcbkit.io): https://app.pcbkit.io/demo/pong. Placed and routed by PCBKit; the sketch builds and runs in the browser.
